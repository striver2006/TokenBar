# v1.7.0 发布记录

日期：2026-10-09

## 发布内容

- macOS / Windows 新增 Codex 订阅额度查询，复用本机 Codex 的 ChatGPT 登录。
- OpenAI 设置新增 API / Codex 订阅模式与可执行文件路径配置，保留旧配置和 API Key。
- 按服务端百分比、周期和重置时间显示额度，兼容单窗口；异常数据不显示虚构额度。
- macOS Info.plist 与 Windows csproj 的版本统一升级至 1.7.0。
- 发布工作流在打包前执行 macOS 与 Windows 自动化测试。
- 本次默认仅交付 Codex 功能，工作区已有的 Gemini 修复保留、不混入提交。

## 架构

`CodexService` 使用本机 `codex app-server` 的 stdio JSON-RPC，在 initialize / initialized 握手后调用 `account/read` 与 `account/rateLimits/read`。仅接受 ChatGPT 登录，OAuth 凭证和刷新由 Codex 管理。此路径由 Codex 子进程联网，查询最长 20 秒，结束后回收进程。额度优先读取 `rateLimitsByLimitId.codex`，兼容 `rateLimits`。

## 发布方式

发布前对暂存区生成的独立代码快照执行 macOS 测试：182 项通过，0 失败。Windows 完整编译与测试由发布 CI 在 Windows runner 上执行。

- 在当前 main 分支提交，推送 GitHub 与 GitCode。
- 创建 v1.7.0 标签，触发既有 GitHub Release 流程。
- CI 生成 macOS universal、Windows x64 / ARM64 便携包与安装包，以及 SHA256SUMS.txt。
- CI macOS 附件未采用 Developer ID 签名和 Apple 公证；此前本机签名包的公证与本次发布分开。
