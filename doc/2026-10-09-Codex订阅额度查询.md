# Codex 订阅额度查询开发记录

日期：2026-10-09

## 实现

- macOS / Windows 的 OpenAI 设置页新增 API / Codex 订阅模式选择，沿用既有样式。旧配置默认 API 模式，已有 API Key 保留。
- 新增 CodexService，通过本机 `codex app-server` 的 stdio JSON-RPC 握手，读取账号与订阅限额。仅接受 ChatGPT 登录，凭证由 Codex 管理。
- 优先读取 `rateLimitsByLimitId.codex`，兼容旧 `rateLimits`；使用服务端百分比、窗口长度和 Unix 重置时间，支持单窗口。空或异常窗口报告查询失败，不伪造满额。
- 查询最长 20 秒，退出时清理查询进程。切换模式后清除旧模式额度，并丢弃已过时的模式查询结果。
- 支持自动查找本机 Codex，以及显式设置可执行文件路径。用户授权发布后，macOS / Windows 版本统一升级到 1.7.0。

## 验证

- macOS：完整工作区 183 项测试通过，包含新增解析、设置兼容、RPC 握手、API Key 登录拒绝、进程超时测试。
- v1.7.0 发布范围仅含 Codex 改动；从暂存区生成的独立代码快照 182 项测试通过，未混入工作区既有 Gemini 修复。
- 当前账号实测：ChatGPT 登录成功，服务端返回单个每周窗口，已用 2%，包含重置时间。
- Windows：本机缺少 Microsoft.NET.Sdk.WindowsDesktop，完整 WPF 编译与 xUnit 测试需要在 Windows 环境执行。另用 .NET 8 临时验证项目编译实际 CodexService.cs，解析检查通过（UI/模型依赖以临时最小桩替代，不能视为完整 Windows 编译）。

## 使用范围

- 查询订阅百分比和重置时间，不推算剩余消息数或 token 数，不统计额外购买的 credit 余额。
- 依赖已安装且支持账号 RPC 的 Codex。复用其当前账号和 CODEX_HOME 配置；TokenBar 不管理登录或更换账号。
