# Mac Codex 启动环境修复

Mac 登录后自动启动的 TokenBar 可能只继承系统默认 PATH。自动检测到的 Homebrew Codex 是通过 `/usr/bin/env node` 启动的脚本，而 Node.js 位于 `/opt/homebrew/bin` 时，Codex 会立即退出，订阅额度无法显示。

启动 Codex 子进程时，在继承的 PATH 末尾补充 `/opt/homebrew/bin`、`/usr/local/bin` 和用户的 `.local/bin`，避免覆盖已有目录优先级或其他环境变量。没有继承 PATH 时使用系统常见目录作为基础。此调整仅影响 Codex 子进程，不修改系统环境或登录凭证。

版本升级至 1.7.9；macOS 全量 201 项测试通过，受限 PATH 下的 Codex 测试通过。发布工作流先创建草稿，替换为公证版 Mac 包并校验后再正式发布。
