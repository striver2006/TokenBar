# v1.7.1 Gemini 登录修复发布记录

日期：2026-10-10

## 发布范围

用户确认将此前工作区已有的 Gemini 修复一起发布。v1.7.0 已公开发布，因此以 v1.7.1 补充发布，保留 v1.7.0 标签和附件。v1.7.1 包含 v1.7.0 的 Codex 订阅额度查询功能。

## 修复内容

- macOS 自有 Google 登录成功后将 refresh token 写入专用钥匙串条目；写入失败保留本次运行的内存凭证并记录错误。
- 设置保存时编码 geminiOwnAccount，避免重启后丢失登录账号显示。
- 自有登录额度查询不返回 token 给 Antigravity 的兜底字段，避免覆盖另一条凭证链路。
- 启动时优先检测自有 Google 登录，已有自有登录时不再读取 Antigravity 凭证。
- 新增账号设置编码往返回归测试。
- macOS / Windows 版本号统一升级到 1.7.1；Windows 功能保持 v1.7.0 行为。

## 验证与发布

提交前完整 macOS 自动化测试 183 项通过，0 失败，包含新增的账号信息编码往返回归测试。发布通过现有 CI 执行 macOS / Windows 测试、构建双平台安装包，并生成校验文件。CI macOS 发布包未采用 Developer ID 签名及 Apple 公证。
