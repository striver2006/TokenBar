## 分发流程

1. 更新版本元数据并使用 `build_app.sh --distribute` 构建 Mac universal 包。
2. 执行 `notarize_app.sh`，检查公证、staple、Gatekeeper 和校验和。
3. 提交版本变更，推送当前 main 与 v1.7.3 标签到 origin、gitcode。
4. 由 Release workflow 构建 Windows x64/arm64 安装包与便携包，并执行双端测试。
5. GitHub 使用本机签名、公证的 Mac zip 替换 CI Mac zip，重新生成完整 SHA256SUMS.txt。
6. 将同一批 5 个二进制包与校验文件发布至 GitCode，并回读附件和校验和。
